# Статус данных сечений

Таблицы с суффиксом `_screening` — предварительные кривые для разработки вычислительного контура. Они воспроизводят пороги и характерные порядки величин процессов в D₂, но не должны цитироваться как экспериментальные данные конкретного автора или базы.

Назначение файлов:

- `e_D2_momentum_screening.csv` — эффективное транспортное сечение e–D₂;
- `e_D2_ionization_screening.csv` — полная ударная ионизация D₂;
- `e_D2_dissociation_screening.csv` — эффективная диссоциация;
- `e_D2_excitation_screening.csv` — свёрнутая электронная возбуждённая группа;
- `Dplus_D2_momentum_screening.csv` — эффективное импульсное/перезарядочное сечение D⁺–D₂.

Для следующей версии следует:

1. выгрузить выбранные процессы e–D₂ из LXCat или MCCC вместе с метаданными набора;
2. отдельно загрузить D⁺–D₂, D₂⁺–D₂ и D₃⁺–D₂;
3. сохранить исходные единицы, DOI/версию базы и дату доступа;
4. проверить покрытие энергии, монотонность сетки и отсутствие отрицательных значений;
5. повторить чувствительность по опубликованным неопределённостям, а не по общим множителям.

Рекомендуемые первичные источники данных:

- [LXCat](https://nl.lxcat.net/) — каталог наборов столкновительных данных;
- [MCCC/Laporta D₂ entries in LXCat](https://master.lxcat.net/contributors/);
- [MCCC: vibrationally resolved ionization of molecular hydrogen isotopologues](https://doi.org/10.1016/j.adt.2023.101573);
- [NIST Atomic and Molecular Data](https://www.nist.gov/pml/atomic-and-molecular-data).
