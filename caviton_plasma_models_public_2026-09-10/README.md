# Caviton plasma models

Воспроизводимый исследовательский комплекс расчётных моделей кавитонной динамики и передачи энергии дейтронам в низкотемпературной D₂-плазме.

Публичная редакция восстановлена из идентифицирующего Word-листинга от 10.08.2026. Зарегистрированное ядро включает уровни 1–5, расширения 4.5–4.8, конфигурации и тесты. Исходные файлы ядра не изменялись: их совокупный SHA-256 равен:

```text
bfc4f949a1d08f720941599c768e24edfcd256412e3362120c69c8f4e582aad1
```

## Научный статус

Комплекс предназначен для скрининговых и методических расчётов. Он не подтверждает достижение дейтронами 1–100 кэВ, энергетическое самоподдержание D–D-контура или работоспособность физической установки. Результаты уровней с предписанными полями требуют самосогласованной EM-PIC/MCC-верификации.

Таблицы в `data/cross_sections/` являются скрининговыми входными данными. Для количественной публикации их следует заменить прослеживаемыми версиями с указанием базы данных, набора, версии, даты доступа и правил интерполяции.

## Установка

Требуется Python 3.10 или новее. Рекомендуется отдельное виртуальное окружение:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Проверка

```bash
python verify_registered_sources.py
python -m unittest discover -s tests -v
```

В зафиксированной редакции выполняются 36 автоматических тестов. Они проверяют программные инварианты и отдельные аналитические пределы, но не заменяют экспериментальную или кластерную физическую верификацию.

## Запуск моделей

Каждый уровень имеет собственный YAML-файл. Например:

```bash
python plasma_level1.py --config config.yaml
python plasma_level2.py --config config_level2.yaml
python plasma_level3.py --config config_level3.yaml
python plasma_level4.py --config config_level4.yaml
python plasma_level5.py --config config_level5.yaml
```

Доступные параметры конкретного модуля:

```bash
python plasma_level1.py --help
```

Расширения запускаются аналогично с соответствующими файлами `config_level45.yaml`–`config_level48.yaml`. Полноэлектронный файл `smilei_level47_full.py` требует отдельно установленную совместимую среду Smilei.

## Структура

- `plasma_level*.py`, `plasma_extrema.py` — расчётные модули;
- `config*.yaml` — конфигурации;
- `tests/` — автоматические тесты;
- `data/cross_sections/` — скрининговые таблицы сечений;
- `docs/` — описание происхождения и ограничений;
- `verify_registered_sources.py` — контроль целостности зарегистрированного ядра.
